# GLI 디자인 규칙 v1

`design/claude-ui-refresh` 브랜치 작업 기준. 핸드오프 문서 §7·§8·§9를 대체하는 세부 규정.

전제: 사용자는 **수천만~수억 원 단위 해외 자산을 검토하는 40~60대 투자자**다. 반복 사용하는 실무 탐색 도구이며, 판단 근거를 읽어야 하는 화면이다. 밀도보다 가독성이 우선한다.

---

## 1. 타이포그래피

서체는 **Pretendard** 단일. 한글 자소 균형과 숫자 판독성이 좋고 400~700 굵기가 고르다. 장식 서체를 쓰지 않고 굵기·크기·색으로만 계층을 만든다.

### 크기 (데스크톱 / 모바일 ≤768px)

| 역할 | 크기 | 굵기 | 행간 |
|---|---|---|---|
| H1 페이지 제목 | 44 / 30px | 700 | 1.3 |
| H2 섹션 제목 | 32 / 25px | 700 | 1.35 |
| H3 하위 섹션 | 24 / 20px | 600 | 1.4 |
| H4 카드 제목 | 19 / 18px | 600 | 1.45 |
| 본문 | 16px | 400 | 1.75 |
| 보조 정보 (위치·사양·환산가) | 15px | 400 | 1.6 |
| 최소 하한 (배지·캡션·법적 문구) | **14px** | 500~600 | 1.5 |
| 버튼 라벨 | 16px | 600 | 1.2 |
| 입력창 | 17px | 400 | — |

**14px 미만은 어떤 경우에도 쓰지 않는다.** 이전 시안의 10.5·11·11.5·12·12.5px는 전부 폐기.

> 핸드오프 §8은 12px를 푸터 법적 문구에 허용했으나, 대상 연령대를 고려해 **14px로 상향**한다. 대신 4열 그리드를 3열로 낮춰 공간을 확보한다.

### 규칙

- 자간은 0 또는 양수. 음수 금지.
- 한글은 `word-break: keep-all`.
- 긴 영문·URL·통화 범위는 `overflow-wrap: anywhere`.
- 제목에 `<br>`을 넣을 때 `max-width`를 함께 걸지 않는다 (줄바꿈이 무력화된다).
- 카드 제목 최대 2줄, 상세 페이지 제목은 전체 표시.

## 2. 색상

딥 그린 계열을 브랜드 축으로 삼는다. 아시아 부동산 투자의 성장·안정 인상과 맞고, 금융권의 흔한 남색과 구분된다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--forest` | `#0F3D33` | 브랜드 기본. 헤더 스크림, 다크 섹션, 강조 배지 |
| `--green` | `#1B6B58` | 주요 액션 버튼, 활성 필터, 링크 |
| `--green-700` | `#15584A` | 호버·프레스 |
| `--green-100` | `#E8F2EE` | 선택 상태 틴트 |
| `--gold` | `#7A5214` | Trust Score 수치. 그 외 사용 금지 |
| `--gold-100` | `#F5EEE1` | Trust 칩 배경 |
| `--ink` | `#14201D` | 본문 |
| `--ink-2` | `#4C5652` | 보조 텍스트 (본문 대비 4.5:1 확보) |
| `--paper` | `#FAF9F6` | 페이지 바탕 |
| `--surface` | `#FFFFFF` | 카드·패널 면 |
| `--line` | `#E2E0D9` | 경계선 |
| `--red` | `#A63D34` | 경고·확인 필요 |

- 모든 텍스트는 **4.5:1 이상**. 24px 이상 굵은 텍스트만 3:1 허용.
- 골드는 Trust Score 전용. 다른 곳에 쓰면 신호가 희석된다.
- 배경 그라데이션 금지. 사진 위에는 **단색 반투명 스크림** (`rgba(15,61,51,.72)`).

---

## 3. 형태와 깊이

- 모서리 **6px** 통일. 알약(999px)은 필터 칩에만 허용 — 클릭 가능함이 즉시 읽혀야 하는 요소이기 때문.
- 그림자는 두 단계만.
  - 기본 `0 1px 3px rgba(20,32,29,.07)`
  - 호버 `0 6px 18px rgba(20,32,29,.11)`
  - 이보다 강한 그림자 금지.
- 카드 안에 장식용 카드를 중첩하지 않는다.
- 섹션을 불필요하게 카드로 감싸지 않는다.

---

## 4. 히어로 — 규칙 완화

핸드오프 §7은 큰 장식을 금지하지만, 배경 이미지가 전혀 없으면 자산 플랫폼으로 읽히지 않는다. 절충:

- 이미지 밴드 **높이 360px 고정** (풀스크린 금지).
- 단색 스크림 위에 제목·부제만. 통계·CTA를 얹지 않는다.
- **검색창은 밴드 아래 본문 영역**에 배치. 탐색 도구의 성격을 유지하고, 이미지 위 흰 박스의 홍보성 인상을 피한다.
- 지표(4개국·16건 등)는 검색창 아래 조용한 한 줄로.

---

## 5. 터치와 접근성

- 모든 클릭 대상 최소 **48×48px** (핸드오프 44px에서 상향 — 대상 연령대 고려).
- 포커스: `outline: 2px solid var(--green); outline-offset: 2px`. 기본 링을 제거만 하고 대체하지 않는 것 금지.
- 아이콘만 있는 버튼에 `aria-label` 필수.
- 사진 위 배지는 불투명 배경을 깐다. 투명 배지는 사진에 따라 사라진다.

---

## 6. 레이아웃

- 자산 그리드 **3열** (1280px 기준). 1024px 2열, 768px 이하 1열.
- 카드 내부는 `flex-direction: column`에 사양 블록 위 `margin-top:auto` — 제목 길이가 달라도 가격·구분선·버튼이 같은 행에서 정렬된다.
- 제목과 가격은 독립 영역. `position:absolute` 금지.
- 360px에서 가로 스크롤 없음.

## 7. 개발팀 전달 제안 (구현하지 않음)

> **제안 1 — 지도 뷰**
> 문제: 4개국에 흩어진 자산을 목록만으로는 위치 비교가 불가능하다.
> 사용자 영향: 지역 선택이 국가 필터 수준에 머문다.
> 제안: 목록/지도 전환. 핀에 가격 라벨.
> 기존 기능 변경: 없음(추가).

> **제안 2 — 매물 이미지 출처**
> 문제: 캄보디아 8건이 Unsplash 스톡 사진이다. "검증"을 파는 서비스에서 메시지를 훼손한다.
> 사용자 영향: 신뢰 하락.
> 제안: 실사진 확보 전까지 카드에 `참고 이미지` 고지 표기(이번 시안에 반영).
> 기존 기능 변경: 없음(표시만).

> **제안 3 — Trust Score 근거 공개**
> 문제: 65와 88의 차이를 사용자가 해석할 수 없다.
> 사용자 영향: 핵심 차별 기능이 장식으로 소비된다.
> 제안: 등급(A/B/C) 병기 + 상세에서 완전성·최신성·일관성 분해 표시. 산식은 변경하지 않는다.
> 기존 기능 변경: 없음(표시만).
