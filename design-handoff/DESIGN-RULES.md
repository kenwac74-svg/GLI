# GLI 디자인 규칙 v2

`design/claude-ui-refresh` 브랜치 기준. v1(딥그린 단일 팔레트 / 6px 라운드)을 대체한다.

전제: 사용자는 **수천만~수억 원 단위 해외 자산과 개발 프로젝트를 검토하는 40~60대 투자자**다. 반복 사용하는 실무 탐색 도구이며, 판단 근거를 읽어야 하는 화면이다. 밀도보다 가독성이 우선한다.

v2에서 바뀐 것: 라임 액센트 도입, 라운드 6→14px, 그림자 2단 레이어, 숫자 전용 서체 분리, 마켓플레이스 필터 레일, 랜딩 페이지 신설.

---

## 1. 타이포그래피

**본문·제목: Pretendard.** 한글 자소 균형과 굵기 분포가 고르다.
**숫자·라틴 지표: Schibsted Grotesk** (`--fn`). 가격·Trust Score·퍼센트·연도 등 판독이 중요한 수치에만 쓴다. 반드시 `font-variant-numeric: tabular-nums`를 함께 건다.

```css
--f:  "Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", sans-serif;
--fn: "Schibsted Grotesk", "Pretendard Variable", Pretendard, sans-serif;
```

### 크기 (데스크톱 / 모바일 ≤768px)

| 역할 | 크기 | 굵기 | 행간 | 자간 |
|---|---|---|---|---|
| H1 히어로 | 56~60 / 42px | 800 | 1.18 | -0.03em |
| H2 섹션 제목 | 34 / 25px | 700 | 1.35 | 0 |
| H3 하위 섹션 | 24 / 20px | 600 | 1.4 | 0 |
| H4 카드 제목 | 19 / 18px | 600 | 1.45 | -0.01em |
| 본문 | 16px | 400 | 1.75 | 0 |
| 리드문 (히어로 부제) | 19px | 400 | 1.7 | 0 |
| 보조 정보 | 15px | 400 | 1.6 | 0 |
| 최소 하한 | **14px** | 500~600 | 1.5 | 0 |
| 키커 (대문자 라벨) | 13~14px | 700 | — | 0.1em |
| 카드 가격 (`--fn`) | 27px | 700 | 1.2 | -0.025em |
| 히어로 지표 (`--fn`) | 28px | 700 | 1.25 | -0.02em |

**14px 미만 금지.** 예외 없음. `.ui-bar` 같은 목업 내부 캡션(12px)은 실제 UI가 아닌 장식이므로 제외.

### 규칙

- 한글 자간은 0 또는 양수. 음수는 **한글이 섞이지 않은 대형 제목에만** (-0.02~-0.03em).
- 한글 `word-break: keep-all`, 긴 영문·통화 범위 `overflow-wrap: anywhere`.
- 리드문·인용문에 `text-wrap: pretty`.
- 제목에 `<br>`을 넣을 때 `max-width`를 함께 걸지 않는다.

## 2. 색상

딥그린은 **면(surface)** 색이고, 라임은 **행동(action)** 색이다. 이 분리를 지킨다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--forest` | `#0F3D33` | 다크 섹션 배경, 헤더 스크림, 활성 필터 칩 |
| `--green` | `#1B6B58` | 링크, 키커, 보조 강조 |
| `--green-700` | `#15584A` | 링크 호버, 라벨 텍스트 |
| `--green-100` | `#E8F2EE` | 선택 상태 틴트, 아바타 배경 |
| `--green-300` | `#9CC9BC` | 푸터 키커 |
| `--lime` | `#C8F04A` | **주요 CTA 배경**, 다크 위 강조 텍스트, 단계 번호 |
| `--lime-600` | `#B2DE2E` | CTA 호버, 차트 선·바 |
| `--lime-700` | `#5F7D0B` | 밝은 배경 위 라임 계열 텍스트 (대비 확보) |
| `--lime-100` | `#F2FBDA` | 차트 면적 채움 |
| `--gold` | `#7A5214` | GLI Cash 유료 단계, 실사 서비스 블록 |
| `--gold-100` | `#F5EEE1` | 골드 블록 배경 |
| `--ink` | `#14201D` | 본문 |
| `--ink-2` | `#4C5652` | 보조 텍스트 |
| `--paper` | `#FAF9F6` | 페이지 바탕 |
| `--surface` | `#FFFFFF` | 카드·패널 |
| `--line` | `#E4E2DB` | 경계선 |
| `--red` | `#A63D34` | 경고, 하락, 관심 하트 활성 |

### 규칙

- **라임 위 텍스트는 항상 `--forest`.** 흰색 금지 (대비 미달).
- **밝은 배경 위 라임 텍스트는 `--lime-700`.** `--lime` 원색을 흰 배경 위 텍스트로 쓰지 않는다.
- 골드는 GLI Cash·현지 실사 유료 영역 전용. Trust Score 수치는 v2에서 그린 계열로 이동했다.
- 배경 그라데이션은 **다크 섹션의 라디얼 글로우에만** 허용:
  ```css
  radial-gradient(900px 540px at 80% 4%, rgba(200,240,74,.17), transparent 62%),
  radial-gradient(760px 520px at 4% 98%, rgba(27,107,88,.6), transparent 66%)
  ```
  밝은 섹션에는 그라데이션 배경 금지.
- 그라데이션 텍스트는 **랜딩 H1 하나뿐**. 다른 곳에 복제하지 않는다.
- 사진 위 텍스트는 단색 반투명 스크림 `rgba(15,32,29,.72)`.
- 모든 텍스트 **4.5:1 이상**. 24px 이상 굵은 텍스트만 3:1.

## 3. 형태와 깊이

```css
--r: 14px;      /* 카드, 패널, 버튼, 입력창 */
--r-sm: 10px;   /* 셀렉트, 토글, 소형 컨트롤 */
999px           /* 필터 칩, 배지, 아바타 */
18px            /* 히어로 카드, 다크 섹션 쇼케이스 블록 */
```

그림자는 2단 레이어 두 종류만:

```css
--sh:   0 1px 2px rgba(20,32,29,.05), 0 4px 14px rgba(20,32,29,.05);
--sh-h: 0 2px 4px rgba(20,32,29,.05), 0 14px 34px rgba(20,32,29,.12);
```

다크 배경 위 부유 카드만 예외: `0 34px 80px rgba(0,0,0,.42)`.

- 카드 안에 장식용 카드를 중첩하지 않는다.
- 섹션을 불필요하게 카드로 감싸지 않는다.

## 4. 화면별 구조

### 랜딩 (`view: land`)
배경 리듬을 지킨다: **딥 → 밝음 → 딥 → 밝음 → paper → 밝음 → 딥**.

1. 히어로 (forest + 라디얼 글로우) — 그라데이션 H1 / 리드문 / 지표 3칸 / CTA 2개 / 우측 자산 카드
2. Trust Score 티커 (자동 마퀴, `prefers-reduced-motion` 존중)
3. 파트너 스트립
4. HOW IT WORKS 3단계
5. INSIDE GLI (다크) — 브라우저 프레임 UI 목업 3블록, 지그재그 배치
6. WHY GLI 4블록
7. FEATURED 자산 3건
8. 대표 인용문 밴드 (paper)
9. 후기 롤링 배너 (hover 시 정지)
10. NEWSROOM 3건
11. FAQ 아코디언
12. CTA 밴드

### 마켓플레이스 (`view: home`)
히어로 → AI 검색 컴포저 → **스티키 필터 레일** → 지표 스트립 → 결과 줄(건수 / 정렬 / 그리드·리스트) → 자산 그리드.

필터 레일은 한 줄 가로 스크롤: `국가 5개 | 거래유형 5개 | 관심자산 토글`. 구분자는 1px 세로선.

### 자산 상세 (`view: detail`)
좌: 갤러리 · 요약 · 강점/확인사항. 우 사이드바 순서 고정:
`Trust/Verification 지표 → 스펙 스트립(침실·욕실·면적·거래유형) → Trust Score 추이 차트 → 등급 탭 → 등급별 본문`

### GLI 소개 (`view: about`)
다크 히어로 → 회사 지표 → 법인 구조 3블록 → CORE TEAM → 파트너 → 백서 CTA.

## 5. 자산 카드

- 사진 비율 16:10, 카드 **전체가 클릭 영역**. 하단에 별도 CTA 버튼을 두지 않는다.
- 사진 위 좌상단 태그 스택(추천순위 / GLI 추천·검증 / 거래유형), 우상단 하트 48×48px.
- 본문: 위치 → 제목 → 가격(`--fn` 27px) + Trust pill → 사양 한 줄.
- 영문 제목·상세 설명은 카드에 넣지 않는다. 상세 페이지로.
- 하트 클릭은 반드시 `stopPropagation` — 카드 이동과 충돌한다.

---

## 6. 터치와 접근성

- 모든 클릭 대상 최소 **48×48px** (필터 칩 40px 예외 — 가로 레일 밀도상).
- 포커스: `outline: 2px solid var(--green); outline-offset: 2px`.
- 아이콘 전용 버튼에 `aria-label` 필수.
- 마퀴 애니메이션은 `@media (prefers-reduced-motion: reduce)`에서 정지.
- 사진 위 배지는 불투명 배경.

---

## 7. 레이아웃

- 자산 그리드 3열(1280px) → 2열(1024px) → 1열(768px).
- 팀 그리드 4열 → 2열(900px).
- 카드 내부 `flex-direction: column` + 사양 블록 `margin-top:auto`.
- `position:absolute`로 제목·가격을 배치하지 않는다.
- 360px에서 가로 스크롤 없음.

---

## 8. 이미지

- **`<img src="{{ hole }}">` 금지.** 스트리밍 단계에서 리터럴 문자열을 URL로 요청해 404가 난다. `background-image`를 인라인 스타일로 넘긴다.
- `.ph` 같은 클래스에서 `background` 단축 속성을 쓰면 `background-size`가 초기화된다. `background-color`를 쓸 것.
- 인물 사진은 `background-position: center 22%` (얼굴 위치 기준).
- 스톡 사진에는 `참고 이미지` 고지를 표기한다.

## 10. 반업형 규칙 (2026-08-12 추가)

### 모바일 입력

- 입력 요소 글자는 **16px 이상**. 더 작으면 iOS Safari가 포커스 시 화면을 자동 확대한다.
- 모바일에서 textarea와 실행 버튼은 세로 배치, 버튼은 `width:100%` / `min-height:54px`.
- 입력창은 낮은 높이로 시작해 내용에 따라 확장한다.

### 가로 스크롤 집합

모바일에서 세로로 쓰이면 화면을 잡아먹는 칩 집합은 가로 스크롤로 전환하고 `scroll-snap-type: x mandatory`를 건다. 다음 항목의 일부가 보여 스크롤 가능성이 드러나게 한다 (`max-width:78%`).

적용 대상: 예시 질문 칩(`.prompt-row`), 상세 등급 탭(`.tiers`, `scroll-snap-align:center`), 갤러리 썸네일(`.thumbs`).

### 단계 표시의 모바일 처리

단계가 3개 이상인 진행 표시는 모바일에서 전수 나열하지 않는다. `n/N 현장단계명 중` 형식으로 줌이고(`.pipe-mob`), 데스크톱 전수 표기는 `display:none`한다.

### 지표 카드

지표 3개는 모바일에서도 3열을 유지한다. 세로 1열로 바꾸면 진입 화면이 길어지며 CTA가 밀려난다. 숫자 21px / 라벨 13px로 축소한다.

### 고정 줄바꿈

모바일 breakpoint에서 헤드라인의 고정 `<br>`을 `display:none`으로 해제해 자동 줄바꿈을 허용한다.

### 메뉴

열린 모바일 메뉴는 `max-height:calc(100vh - <헤더 높이>)` + `overflow-y:auto` + `overscroll-behavior:contain`.

### 확인 폭

360 / 390 / 430 / 768 / 1024 / 1440px에서 가로 넘침과 제목·가객 겹침이 없어야 한다.

## 11. 상태 표현 규칙 (2026-08-12 추가)

진행되는 절차를 보여주는 UI는 다음 4상태를 갖춘다.

| 상태 | 클래스 | 색 | 기호 |
|---|---|---|---|
| 대기 | `.is-idle` | `--ink-2` / 원형 `#B9C6C1` | 숫자 |
| 진행 | `.is-active` | `--lime` + pulse | 숫자 |
| 완료 | `.is-done` | `--green` | `✓` |
| 오류 | `.is-error` | `--red` | `!` |

- **가짜 진행률 퍼센트를 쓰지 않는다.** 산출 근거가 없는 숫자는 신뢰를 깎는다.
- 완료 후에도 전 단계를 done 상태로 남긴다. 사라지면 무엇을 거쳤는지 알 수 없다.
- 상태를 색상만으로 구분하지 않는다. 기호도 함께 바뀐다.
- 상태 변화를 음성 지원에 전달하려면 컨테이너에 `aria-live="polite"`.
- 진행 에니메이션은 reduced-motion에서 정지한다.

## 12. 개발팀 전달 제안 (구현하지 않음)

> **제안 1 — 지도 뷰**
> 문제: 4개국 자산을 목록만으로는 위치 비교가 불가능하다.
> 제안: 목록/지도 전환, 핀에 가격 라벨. 기존 기능 변경 없음(추가).

> **제안 2 — 매물 이미지 출처**
> 문제: 캄보디아 8건이 Unsplash 스톡 사진이다. "검증"을 파는 서비스에서 메시지를 훼손한다.
> 제안: 실사진 확보. 그 전까지 `참고 이미지` 고지 유지(반영됨).

> **제안 3 — Trust Score 근거 공개**
> 문제: 65와 88의 차이를 사용자가 해석할 수 없다.
> 제안: 등급(A/B/C) 병기 + 완전성·최신성·일관성 분해 표시(반영됨). 산식은 변경하지 않는다.

> **제안 4 — 카드 사진 캐러셀**
> 문제: 자산당 사진이 1장뿐이라 Lofty 수준의 탐색감이 나오지 않는다.
> 제안: 자산당 3장 이상 확보 시 카드 내 캐러셀 + 도트. 현재는 `사진 N장` 카운트 칩으로 대체.

> **제안 5 — 수익 시뮬레이터**
> 문제: 유료 등급의 가치가 자료 열람에 그친다.
> 제안: PREMIUM 등급에 임대수익률·보유기간·환율 가정을 넣는 시뮬레이터. `monthly`·`krw` 실데이터로 계산 가능.
