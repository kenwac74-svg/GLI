이번 개편의 핵심 변경

  1. 진입 화면이 바뀌었습니다. 기존에는 접속 즉시 자산 목록이 나왔습니다. 이제 랜딩이 기본이고, 마켓플레이스는 자산 탐색 메뉴로 들어갑니다.
  2. 액센트 컬러 도입. 딥그린 단일 팔레트에서 딥그린(면) + 라임(행동) 2축으로. CTA·활성 필터·차트가 라임으로 통일됩니다.
  3. 마켓플레이스 필터 통합. 흩어져 있던 국가 탭·카테고리 박스·거래유형 세그먼트를 스티키 칩 레일 하나로 합쳤습니다. 동작하지 않던 카테고리 박스는 제거했습니다.
  4. 자산 카드 재설계. 카드 전체가 클릭 영역이 되고 하단 CTA 버튼을 뺐습니다. 가격을 전용 서체·크기로 분리했습니다.
  5. 상세 우측 사이드바 확장. 스펙 스트립과 Trust Score 추이 차트를 추가했습니다.
  6. 형태 토큰 조정. 라운드 6→14px, 그림자 1단→2단 레이어.

구현 시 주의

  1. 시안의 renderVals()는 뷰 모델입니다. 정렬·필터·등급 판정·차트 경로 계산을 그대로 옮기면 됩니다.
  2. 카드 하트 버튼은 stopPropagation 필수입니다. 빠뜨리면 카드 클릭과 충돌합니다.
  3. 이미지는 <img src> 대신 background-image를 씁니다. 이유는 DESIGN-RULES.md 8절에 있습니다.
  4. 마퀴 애니메이션(티커·후기 배너)은 prefers-reduced-motion을 존중해야 합니다.
