# 데모 전용 가상 데이터

이 시안은 **"완성되었을 때의 모습"을 보여주는 데모**다. 실제 데이터가 아직 없는 영역은 그럴듯한 값으로 채워 두었다. 실개발 시 아래 항목은 **반드시 실데이터로 교체하거나 제거**한다.

소스: `source/gli-demo.dc.html` — 로직 클래스 `renderVals()` 내부.

| 위치 | 식별자 | 내용 | 처리 |
|---|---|---|---|

## 실데이터인 것 (교체 불필요)

- 자산 16건 — `lib/assets.ts`(캄보디아 8) + `lib/partner-assets.ts`(파트너 8) 실값
- 뉴스 6건 — 라이브 사이트 기사
- 백서 5개 문서 — 라이브 `/whitepaper`
- 멤버십 3플랜 가격·혜택 — `lib/membership-plans.ts` 실값
- 법인 구조·주소 3곳 — 확정 정보
- 경영진 8명 이름·직책·경력 — 확정 정보
- 파트너 4곳 — 실제 MOU 체결처
