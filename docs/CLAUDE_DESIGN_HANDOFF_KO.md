# GLI 사이트 디자인 협업 핸드오프

## 1. 문서 목적

이 문서는 Claude가 GLI(Global Lifestyle Investment) Web2 MVP의 사이트 디자인을 개선하기 위한 협업 기준이다. Claude는 기존 제품 기능과 사업 정책을 유지하면서 사용자 화면의 시각적 완성도, 가독성, 반응형 품질과 화면 간 일관성을 개선한다.

Claude의 역할은 **디자인 구현과 UI 품질 개선**이다. 제품 정책, 데이터 구조, AI 검색 로직, 수집기, 결제 로직과 배포 구조는 변경하지 않는다.

## 2. 제품 정의

GLI는 특정 국가의 부동산 포털이 아니다. 전 세계의 투자 가능 자산을 탐색하고, AI 탐색과 사람의 검토를 결합해 사용자의 판단을 돕는 플랫폼이다.

현재 MVP의 주요 범위는 다음과 같다.

- 국가별 투자 자산 탐색
- 주거용, 상업용, 레저, 프로젝트 카테고리
- 외부 포털에서 수집한 시장 매물
- GLI가 파트너와 현지 네트워크를 통해 직접 발굴하고 검토한 자산
- GLI AI를 이용한 자연어 상담형 탐색
- GLI Trust Score와 단계별 상세 정보
- Explorer, Investor, Private 멤버십
- GLI Cash를 이용한 플랫폼 내 선불 결제 구조
- 관심 자산, 상담 신청, 뉴스, 공지와 백서

블록체인과 코인은 현재 Web2 MVP 범위가 아니다. UI에 지갑 연결, 스테이킹, 코인 보상 또는 확정 수익처럼 보이는 표현을 새로 추가하면 안 된다.

## 3. 현재 상태

- 공개 사이트: https://gli-ai-property-demo.kenwac74.chatgpt.site/
- GitHub 저장소: https://github.com/kenwac74-svg/GLI
- 개발 스택: React 19, Next.js 16 호환 구조, vinext, TypeScript, CSS, lucide-react
- 현재 로컬 기준 커밋: `14080d0 Fix long asset title and price overlap`
- 전체 검사: 빌드 및 151개 테스트 통과

중요: 공개 사이트의 최신 수정이 GitHub 원격 브랜치보다 앞서 있을 수 있다. Claude는 작업을 시작하기 전에 `app/globals.css`의 `.detail-title`이 제목과 가격을 독립된 Grid 영역으로 배치하고, `.detail-price`가 절대 위치를 사용하지 않는 최신 상태인지 확인한다. 해당 수정이 없으면 임의로 이전 버전에서 작업하지 말고 저장소 동기화를 요청한다. 로컬 기준 변경 커밋은 `14080d0`이지만 GitHub 동기화 방식에 따라 원격 커밋 SHA는 다를 수 있다.

## 4. Git 협업 방식

Claude는 `main` 또는 기존 개발 브랜치에 직접 커밋하지 않는다.

권장 절차:

1. 최신 통합 브랜치를 가져온다.
2. `design/claude-ui-refresh` 브랜치를 만든다.
3. 디자인 관련 변경만 커밋한다.
4. 작업이 끝나면 Pull Request를 만든다.
5. PR에 변경 화면의 PC·모바일 캡처와 변경 이유를 첨부한다.
6. Codex가 기능 회귀와 정책 준수 여부를 검토한 후 병합·배포한다.

Claude 작업 중 Codex는 같은 UI 파일의 병행 수정을 피한다. 충돌이 예상되면 먼저 변경 대상 파일을 합의한다.

## 5. 수정 허용 범위

다음 작업은 허용된다.

- 레이아웃, 여백, 정렬과 시각적 계층 개선
- 타이포그래피 크기, 굵기, 행간과 줄바꿈 개선
- 기존 브랜드 색상의 일관성 개선
- PC, 태블릿, 모바일 반응형 개선
- 버튼, 탭, 입력창, 카드, 상세 정보 패널의 외형 개선
- 포커스, 호버, 선택, 비활성, 로딩과 빈 상태의 시각적 개선
- 접근성에 필요한 대비, 포커스 표시와 터치 영역 개선
- 중복된 디자인 스타일을 공통 토큰이나 재사용 가능한 프레젠테이션 컴포넌트로 정리
- lucide-react 아이콘을 사용한 일관된 아이콘 적용

디자인 개선에 필요한 경우 다음 파일을 수정할 수 있다.

- `app/globals.css`
- `app/components/**`의 프레젠테이션 영역
- 각 페이지의 마크업 구조 중 레이아웃 목적의 최소 변경
- `public/**`의 승인된 로고 및 UI 이미지 자산

## 6. 수정 금지 범위

다음 항목은 변경하지 않는다.

- `app/api/**`
- `db/**`, `drizzle/**`, 마이그레이션
- `ingestion/**`, `workers/**`, 수집기와 출처 정책
- `lib/**`의 검색, 자산, 통화, 멤버십과 AI 로직
- 인증, 결제, 권한, 상담 및 관심 자산 처리 로직
- Trust Score 산식과 검증 상태
- 멤버십 가격과 열람 권한
- GLI Cash 정책
- 외부 매물 출처 링크와 출처 표시 정책
- `.openai/hosting.json`, 환경변수, 배포 설정
- 테스트를 삭제하거나 기대값을 디자인에 맞춰 임의로 약화하는 행위

실제 API 키, `.env` 파일, 운영 자격 증명은 GitHub에 올리지 않는다.

## 7. 브랜드와 디자인 방향

GLI는 투자자가 반복적으로 사용하는 실무형 탐색 서비스다. 관리자 대시보드나 홍보용 랜딩 페이지처럼 보이면 안 된다.

핵심 방향:

- 차분하고 신뢰감 있는 금융·투자 서비스 인상
- 기존 GLI 로고와 네이비, 화이트, 틸 계열 브랜드 색상 유지
- 중요한 상태에는 녹색, 경고에는 제한적인 황색·적색 사용
- 지나치게 어두운 단색 화면이나 한 가지 색조만 사용하지 않기
- 큰 장식, 그라데이션 배경, 장식용 구체, 과도한 그림자 사용 금지
- 섹션을 불필요한 카드로 감싸지 않기
- 카드 안에 또 다른 장식용 카드를 중첩하지 않기
- 카드 모서리는 기존 시스템과 맞추고 특별한 이유가 없으면 8px 이하 유지
- 익숙한 동작에는 lucide 아이콘 사용
- 아이콘만 있는 낯선 버튼에는 툴팁 또는 접근 가능한 이름 제공

## 8. 타이포그래피 기준

- 일반 본문과 주요 UI의 최소 글자 크기는 14px이다.
- 12px는 푸터의 법적 문구, 출처 보조정보, 컴팩트 배지처럼 제한적인 경우에만 사용한다.
- 제목 크기를 화면 폭에 비례해 무제한 확대하지 않는다.
- 문자 간격은 음수로 설정하지 않는다.
- 한국어는 `word-break: keep-all`을 우선 적용한다.
- 긴 영문, URL, 통화 범위는 컨테이너를 침범하지 않도록 `overflow-wrap`을 적용한다.
- 상세 페이지 제목은 생략하지 않고 전체 표시한다.
- 목록 카드 제목은 일정한 카드 높이를 위해 최대 2~3줄로 제한할 수 있다.

## 9. 레이아웃 필수 규칙

- 제목, 가격, 환산가격은 서로 겹치면 안 된다.
- 가격을 제목 위에 `position: absolute`로 배치하지 않는다.
- 제목과 가격은 독립된 레이아웃 영역을 사용하고 공간이 부족하면 세로로 전환한다.
- 고정 형식 요소는 `grid`, `minmax`, `aspect-ratio` 등으로 안정적인 크기를 확보한다.
- 버튼 텍스트, 긴 통화, 긴 국가·지역명 때문에 카드 크기가 갑자기 변하지 않게 한다.
- 데이터가 길어져도 인접 UI를 침범하거나 수평 스크롤을 강제하면 안 된다.
- 모바일에서 의미 없는 단어 단위 줄바꿈과 한 글자만 남는 줄을 최소화한다.
- 모바일 터치 버튼은 최소 약 44px 높이를 확보한다.

## 10. 유지해야 할 정보 구조

### 홈 및 탐색

- GLI의 글로벌 투자 자산 플랫폼 정체성
- 자연어 AI 탐색창
- 국가 선택
- 주거용, 상업용, 레저, 프로젝트 분류
- GLI 검증 또는 GLI 추천 자산과 외부 시장 데이터의 구분
- 사용자가 요청한 국가를 다른 국가로 임의 대체하지 않는 검색 흐름

### 자산 카드

- 자산 유형 및 GLI 검증 상태
- 위치
- 제목
- 주요 사양
- 원 출처 가격과 사용자 언어 기준 환산가격
- Trust Score
- `상세 정보 확인` 버튼

카드의 제목, 가격, 구분선과 버튼 위치는 같은 행의 카드 사이에서 가능한 한 정렬되어야 한다.

### 자산 상세

- 좌측: 이미지 갤러리, 위치, 제목, 가격, 핵심 정보, 자산 요약
- 우측: Trust Score, 검증 진행, 단계별 정보
- 하단 긴 영역: 검토 강점, 추가 확인, 전문가 상담 신청, 관심 자산 추가, 탐색 결과로 돌아가기
- 외부 수집 매물: 출처명과 원문 매물 링크 유지
- 출처에서 제공하지 않은 필드: 삭제하지 않고 `조사 예정`으로 표시하는 현재 정책 유지

### 멤버십

- Explorer: 월 USD 1.99, Basic까지 열람
- Investor: 월 USD 2.99, Standard까지 열람
- Private: 월 USD 10, Premium까지 열람
- 연간 할인: 각각 10%, 15%, 20%
- 관심 자산 등록은 무제한
- 상위 단계 권한은 하위 단계 정보를 포함

## 11. 우선 개선 대상

1. 긴 제목, 긴 가격 범위와 환산가격의 안정적인 배치
2. PC와 모바일의 타이포그래피 일관성
3. 홈의 AI 탐색창과 자산 탐색 흐름의 사용성
4. 자산 카드 높이, 구분선과 버튼 위치 정렬
5. 자산 상세 좌·우 패널의 폰트 크기와 밀도 통일
6. 상세 페이지 하단 행동 버튼의 명확한 우선순위
7. 멤버십 페이지의 가격과 권한 비교 가독성
8. 뉴스, 공지, 백서 등 보조 페이지의 브랜드 일관성

기능 추가보다 위 항목의 완성도를 먼저 높인다.

## 13. 완료 조건

작업은 다음 조건을 모두 만족해야 완료로 본다.

- 제목, 가격, 버튼, 배지와 탭이 어떤 화면 폭에서도 겹치지 않는다.
- 긴 콘텐츠가 카드나 패널 밖으로 튀어나오지 않는다.
- 360px 모바일에서도 가로 스크롤 없이 핵심 흐름을 사용할 수 있다.
- 일반 UI 본문은 14px 이상을 유지한다.
- 키보드 포커스가 보이고 기본 동작이 유지된다.
- 기존 링크와 버튼 동작이 유지된다.
- 외부 출처 링크와 원문 보기 기능이 유지된다.
- `npm run check`가 통과한다.
- PC 및 모바일 전후 비교 캡처를 PR에 첨부한다.
- 변경한 디자인 규칙과 남은 문제를 PR 설명에 기록한다.

## 14. PR 작성 형식

PR 설명에는 다음 내용을 포함한다.

### 변경 목표

사용자 관점에서 해결하려는 디자인 문제를 3줄 이내로 설명한다.

### 주요 변경

- 변경한 화면과 컴포넌트
- 새로 만든 디자인 토큰 또는 공통 패턴
- 반응형 처리 방식

### 변경하지 않은 영역

- 비즈니스 로직
- API와 데이터 모델
- Trust Score 및 멤버십 정책
- 배포 설정

### 검수 결과

- 확인한 화면 폭
- 실행한 검사
- 알려진 제한사항

### 화면 캡처

- 데스크톱 전후
- 모바일 전후

## 15. 의사결정 규칙

디자인 개선 중 정책 또는 기능 변경이 필요해 보이면 직접 구현하지 않는다. PR 또는 별도 메모에 다음 형식으로 남긴다.

> 개발팀 전달 제안: [문제] / [사용자 영향] / [제안] / [기존 기능 변경 여부]

Claude는 GLI의 기존 기능을 새로 해석해 바꾸는 역할이 아니다. 사용자가 이미 합의한 제품 구조를 더 명확하고 편안하게 사용할 수 있도록 만드는 것이 이번 협업의 목표다.
