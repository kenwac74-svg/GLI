# GLI 멤버십 3단계

상태: 현행 데모 콘텐츠. 가격·할인·포함 열람 범위·관심자산 무제한은 사용자 승인 정책입니다. AI 상담 횟수와 서비스 혜택 표현은 현재 데모 표시값이며 실서비스 운영 조건 확정과 구분해야 합니다.

## Explorer

글로벌 자산 탐색을 가볍게 시작하는 회원

- 월 이용료: $1.99 / 3,000원
- 연간권 할인: 10%
- BASIC 등급까지 무료 열람
- AI 자산 상담 월 60회
- 관심자산 무제한 등록
- 기본 Trust 요약

## Investor

여러 국가와 자산을 비교하는 적극적 투자자

- 월 이용료: $2.99 / 4,500원
- 연간권 할인: 15%
- STANDARD 등급까지 무료 열람
- AI 자산 상담 월 150회
- 관심자산 무제한 등록
- 전체 Trust Report와 우선 상담

## Private

GLI 검증 자산과 현지 실행을 함께 검토하는 회원

- 월 이용료: $10.00 / 15,000원
- 연간권 할인: 20%
- PREMIUM 등급까지 무료 열람
- AI 자산 상담 월 400회
- 관심자산 무제한 등록
- GLI 현지 검증·전문가 상담 우선권

## 관련 안내 원문

Explorer에서 Investor로 변경하면 월 기준 차액은 $1.00(1,500원)입니다. 상위 멤버십은 해당 자산 정보 등급과 모든 하위 등급을 포함합니다.

출처: 멤버십 데이터 및 원본 HTML의 PLANS/CMP/멤버십 안내. 달러와 원화는 각각 책정된 가격이며 실시간 환산값이 아닙니다. 이 문서는 결제·환불·업그레이드 일할 계산 규정을 새로 정의하지 않습니다.
