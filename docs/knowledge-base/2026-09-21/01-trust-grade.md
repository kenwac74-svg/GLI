# GLI Trust Grade

상태: 현재 데모 원문과 데이터 기획 기준. 8등급별 상세 판정 세칙은 미완성입니다.

## 등급 체계

S · A+ · A · B+ · B · C+ · C · D의 8단계입니다. Trust Grade는 멤버십의 정보 열람 등급(LV.1~LV.5)과 별개입니다.

## 부동산 등급별 설명 원문

| 등급 | 설명 |
|---|---|
| S | 확인 항목이 대부분 채워짐 |
| A+ | 확인 항목이 대부분 채워짐 |
| A | 확인 항목이 대체로 채워짐 |
| B+ | 확인할 항목이 남아 있음 |
| B | 확인할 항목이 남아 있음 |
| C+ | 확인이 덜 된 항목이 많음 |
| C | 확인이 덜 된 항목이 많음 |
| D | 확인이 거의 되지 않음 |

설명 원문: 확인되지 않은 항목은 조사 예정으로 표시합니다.

기획 문서의 평가 대상: 객관적 자료가 얼마나 검증되었는가.

기획 문서의 계산 입력:
- 확인된 필드 비율 (`verified_at`이 있는 필드 / 필수 필드)
- 자료 최신성 (`doc_date` 경과)
- 출처 간 불일치 건수 (`conflict_with`)
- 조사량은 넣지 않는다. 치안도 넣지 않는다.

## 프로젝트 등급별 설명 원문

| 등급 | 설명 |
|---|---|
| S | 대형 주체 · 위험 낮음 |
| A+ | 주체·절차 확인됨 |
| A | 주체·절차 확인됨 |
| B+ | 확인된 주체 · 일부 위험 |
| B | 확인된 주체 · 일부 위험 |
| C+ | 자료가 제한적 · 위험 높음 |
| C | 자료가 제한적 · 위험 높음 |
| D | 절차가 불투명 · 위험 매우 높음 |

설명 원문: 등급은 사업 주체와 계약 구조의 위험도를 재집니다.

기획 문서의 계산 입력:
- 사업 주체의 규모·이력·계약 확인 여부
- 계약 구조의 법적 지위 명확성
- 실적 자료 확보 정도
- 인허가·권리 확인 단계

기획 문서 원문: 높은 수익률을 내건 주체의 신뢰도가 낮으면 등급이 내려간다. GLI가 수익률을 판정하는 것이 아니라 주체를 판정한다.

## 미완성 범위

일부 인접 등급은 원문에서도 같은 설명을 사용합니다. S와 A+, B+와 B 등을 구별하는 공개용 상세 필수 증빙·판정 절차·유효기간·예외 규칙은 이 자료에서 확보되지 않았습니다. 등급 설명만으로 수익 보장 또는 구체적인 검증 완료 항목을 추론하면 안 됩니다. AI가 새로운 세칙이나 평가 결과를 만들어서는 안 됩니다.
