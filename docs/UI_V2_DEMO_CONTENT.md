# GLI UI v2 데모 콘텐츠 운영 메모

2026-08-09 적용한 Claude UI Refresh를 공개 데모의 기준 화면으로 사용한다.
현재 목적은 완성 시점의 사용자 경험을 미리 보여주는 것이므로 아직 실데이터가
없는 영역도 완성된 형태의 예시값으로 표시한다.

## 예시값으로 유지하는 영역

- 랜딩 회원 후기 3건
- 대표 인용문
- 랜딩 Trust Score 및 Verification 목업
- 랜딩 뉴스 카드 3건
- 파트너 및 글로벌 네트워크 표시
- 법인·기술·특허 관련 소개 문구

위 항목은 현재 데모에서 사실 검증이나 법률 검토의 완료 여부를 표시하지 않는다.
실서비스 전 관리 데이터 또는 승인된 카피로 교체한다.

## 실제 기능과 연결한 영역

- `/explore` 자연어 AI 검색 및 국가 경계 유지
- 외부 정보 사이트 수집 결과와 출처 링크
- 실제 자산·파트너 자산 데이터
- 환율 환산 가격
- 관심자산, 상담 신청, 검색 결과 복원
- 멤버십 가격과 등급별 열람 범위

## 노출 원칙

- 외부 LLM 제공자 이름은 표시하지 않고 `GLI AI`로 통일한다.
- 내부 자료 작성 시점과 운영 메모는 사용자 화면에 표시하지 않는다.
- 블록체인 실행은 현재 범위에서 제외하지만 미래 생태계 설명은 데모 콘텐츠로
  유지할 수 있다.
