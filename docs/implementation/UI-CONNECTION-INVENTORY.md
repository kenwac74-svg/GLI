## 전문가 문의의 확정 계약

- 로그인 회원만 제출한다. 이름·이메일은 회원 정보 자동 표시, 문의 내용은 필수이다.
- 관련 자산은 상세 진입 시 연결하고 일반 문의는 생략 가능하다. 연락처는 선택이다.
- DB 저장 성공 → 접수번호와 완료 안내까지만 구현한다. 저장 실패에는 완료/번호를 표시하지 않는다. 중복 제출로 접수 건을 불필요하게 늘리지 않는다.
- 자동 이메일, 전문가 배정, 예약, 상담 진행 관리는 이번에 포함하지 않는다. MY에도 상담 진행 영역을 추가하지 않는다.
- 기존 API/DB/인증 경계를 우선하고 실제 샘플 시연 상태와 실결제/실권한을 분리한다. 세부 데이터 계약/디자인은 해당 단계에서 확정한다.

## 제외

임시 관리자, 커뮤니티, 게임, 파트너 전용 등 준비 중 신규 서비스. 제외는 기존 코드/데이터 삭제나 공개 서비스 비활성화 지시가 아니다.
