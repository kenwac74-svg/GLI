# GLI OpenRouter 상담 비교

2026-09-18 / GLI-052 / GS-010, GS-011, GS-012 / 결정 P30, P31.

## 범위와 승인

사용자는 상담 품질을 우선해 OpenRouter 모델을 비교하도록 했고, 최종 대상을 Fable과 Astra로 지정했다. Gemini는 기존 별도 API 연결을 유지한다. 디자인, 공개 사이트, 크롤러 설정, 실제 회원 요금은 변경하지 않았다.

이번 작업은 기존 `규칙 검색 → 후보 → 상담` 구조에 adapter를 추가한 것이다. LLM이 검색 조건을 먼저 이해하고 도구를 다시 호출하는 완성형 상담 아키텍처가 아니다. 비로그인/무료 실제 AI 체험은 승인 방향이지만 공개 할당량과 악용 방지 구현은 남아 있다.

## 재현 방법

서버 전용 `.env.local`에 `OPENROUTER_API_KEY`를 둔다. 키를 공개 환경 변수, 소스코드, Git, 화면, 보고서에 쓰지 않는다. dry-run은 외부 호출이나 키 읽기를 하지 않는다.

```sh
node scripts/compare-advisors.mjs --models=anthropic/claude-fable-5.1,openai/gpt-6-astra
node scripts/compare-advisors.mjs --models=anthropic/claude-fable-5.1,openai/gpt-6-astra --run
```

- 명시 모델 버전을 사용한다. latest/auto 별칭, 모델/제공자 자동 대체, 자동 재시도는 사용하지 않는다.
- 합성 시나리오 3개를 모델마다 각 1회 호출한다. 유료 실행은 `--run`에만 있다. 401/402는 후속 호출을 중단한다.
- 같은 시스템 지침, 대화 이력, 후보, JSON 계약, medium 추론 요청, 8192 출력/추론 상한이다. 모델마다 medium의 내부 연산량은 동일하지 않다.
- 실제 전송 JSON에서 모델 ID만 제외한 해시를 비교하여 입력 동일성을 확인한다. 각 모델의 자체 토크나이저 때문에 입력 토큰 수는 다를 수 있다.
- `work/advisor-comparisons/*.json`에 답변, 질문, 선택 ID, 모델/제공자, 지연, 보고된 비용, 실패 코드를 기록한다. 이 폴더는 Git 제외다. 키, 헤더, 원문 공급자 오류, 내부 추론은 저장하지 않는다.
- fixture는 공개 매물에 등록되지 않는다. 비교 답변은 실제 부동산 추천이나 가격 증거가 아니다.

## 2026-09-18 실호출 결과

첫 6회는 양쪽 모두 응답 성공. Fable이 입력에 있던 내부 Trust 점수를 답변에 노출했다. 기존 승인 P16에 따라 OpenRouter 입력을 8등급만 포함하도록 수정했다. 고정 환율도 상담 입력에서 제외했고, 내부 조건 추출 방식 설명/미실행 조회 주장 금지 지침을 양쪽에 동일하게 추가했다. 다시 6회 호출해 두 모델 모두 성공했다.

| 최종 동일 입력 시나리오 | Fable 5.1 | GPT-6 Astra |
|---|---|---|
| 프놈펜 700달러·2베드룸 후보 비교 | 가격/면적/관리비 미확인 설명은 정확. 내부 ID와 `REVIEWING` 표현, GLI 직접 관리가 아니라는 불필요한 설명 포함 | 같은 사실을 자산명 중심으로 설명. 먼저 확인할 후보와 추가 비용을 간결하게 제시 |
| 총예산 6천만원·즉시 월세·완공 후속 | 매입 목적과 프놈펜 맥락 유지. 사용자가 제한하지 않은 스튜디오/소형 포함 여부를 다시 질문 | 총예산·취득비·완공 유지. 완공과 실제 임대수입 발생을 구별하고 기존 임차인/계약 승계 확인 제시 |
| 시하누크빌만, 후보 없음 | 다른 도시를 추천하지 않음. 조건 완화 질문을 본문과 질문 필드에 중복 | 다른 도시를 추천하지 않고 현재 자료 부재와 시장 전체 부재를 구별. 관리비 포함 여부 한 가지 질문 |

현재 구성에서는 **Astra를 주 상담 후보로 우선 권고**한다. 이유는 말투보다 조건 준수, 불필요한 재질문 감소, 자료 부재를 설명하는 정확성이다. 두 모델 모두 근거 없는 매물/관리비/수익률 수치를 만들지는 않았다. 세 합성 사례의 1회씩 결과이므로 모델 전체의 일반적 우열로 해석하지 않는다. Fable의 상세 비교 역할 적합성도 별도 복잡한 근거 세트로 평가해야 한다.

속도/비용은 선택 기준이 아니라 관측 기록이다. 최종 6회에서 Fable은 약 10.7~19.3초, Astra는 약 3.9~8.8초. 사용자의 이전 시험 순서와 달랐으며 입력/엔드포인트/출력 길이에 따라 달라진다. 두 라운드 12회 응답의 OpenRouter 보고 비용 합계는 **$0.5734025**다. 계정 결제 수수료나 최종 청구 잔액을 검증한 수치가 아니다.

원 보고서: `work/advisor-comparisons/2026-09-18T11-44-34.250Z.json`, `work/advisor-comparisons/2026-09-18T11-48-15.942Z.json`. 각 라운드 내 세 시나리오에서 두 모델 입력 해시가 일치한다. 라운드 간 입력은 위 수정 때문에 다르다.

## 사이트 연결과 남은 일

- 사이트에서 OpenRouter를 선택하려면 서버에 `LLM_PROVIDER=openrouter`, `OPENROUTER_MODEL=승인된_모델_ID`가 추가로 필요하다. 키만 저장한 상태를 모델 전환 완료라고 보고하지 않는다. 이번에는 비교만 하고 기본 모델을 변경하지 않았다.
- 로컬에서 `GLI_LOCAL_AI_PREVIEW=enabled`를 함께 설정하면 비운영 loopback 주소에서 비로그인 테스트가 가능하다. 외부 공개 무료 사용량 정책의 대체물이 아니다. Gemini 개발 모드는 기존 동작을 보존했다.
- 현재 규칙 검색기는 후속 `즉시 월세`를 `rent/residence`로 분류한다. 모델이 답변에서 투자 의도를 바로잡아도 검색 결과를 다시 가져오지는 못한다. GS-010 상태/도구 아키텍처 작업이 필요하다.
- 본문+clarification 질문 중복, 후보가 있어도 아무것도 추천하지 않아야 하는 경우의 선택 schema, 원본 카드와 서버 ID/내용 불일치, 실제 크롤러 결과 기반 장기 상담 검증은 남아 있다.
- 운영 상한, 동시 요청/반복 호출 제한, 실패 안내, 관측 로그, 공개 무료 이용권은 GS-012 후속. 호출 실패 시 공개 API는 기존 `rules` 모드로 돌아가며 내부 비교만 실패로 판정한다. 이를 실제 AI 완료라고 안내하지 않아야 한다.
- `data_collection=deny`는 제공자의 학습 사용 정책을 제한하는 설정이지 서비스 전체 무보관 보장은 아니다. 개인정보 최소 전송 및 장기 대화 보관 정책은 별도다.

## 검증

- `npm run check`: 빌드/DB 검증/175개 시험 통과. 린트 오류 없음, 기존 경고 5개와 큰 번들 경고 있음.
- 빌드 산출물 132개에서 로컬 실제 비밀값 일치 검사: 노출 없음. `.env.local`은 Git 제외.
- `spec:refresh`, `spec:check`: 32개 기능, 46개 경로, 시각 기준 4개 무변경 확인.
- 별도 `tsc --noEmit`: 실패. `.ts` import 설정, Cloudflare 타입, 여러 기존 자산/관리 API 타입 문제가 있어 전체 strict typecheck 통과로 보고하지 않는다. 이 변경 범위 밖의 일괄 수정은 하지 않았다.
- 공개 배포, 커밋/푸시, 기본 모델 변경, 새 사용자 화면은 수행하지 않았다.
