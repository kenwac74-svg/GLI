# 상세 열람 목업 연결

2026-10-13 WORK-SEQUENCE 4단계. 기존 단계별 상세/확인 팝업을 재사용한다. HIST-20261013-011의 소규모 변경 위임을 적용하며 큰 디자인 변경은 없다.

## 구현 계약

- 샘플: BASIC 등 기존 버튼 → Asset Access 확인 팝업 → 준비된 단계별 정보. 취소/바깥 클릭/Escape는 열람 단계 변경 없이 닫는다. Tab은 팝업 안에서 순환하고 취소 시 트리거 초점을 복원한다.
- `scripts/render-claude-handoff.mjs`는 같은 승인 원본을 선택 tier의 unlocked level로 투영한다. FREE 스냅샷과 원본 HTML/CSS는 유지하며 단계별 생성 HTML 기준 hash만 갱신했다. 시안 선택 상태는 계정 entitlement가 아니다.
- 목업 열람은 컴포넌트 상태에만 존재한다. 다른 자산 진입/새 페이지에서 초기화한다. 실제 멤버십/등급/잔액/DB/API는 변경하지 않는다. 샘플 GLI Cash5000 표시는 유지하되 차감하지 않는다.
- 외부 매물: 확보된 publicResources만 관련 자료로 제공한다. 공개 자료를 유료 독점 자료로 바꾸지 않는다. 추가 자료가 없으면 열람 요청 버튼을 비활성화하고 짧은 상태를 표시한다. BASIC 고정 위험 점수/일반 리포트/현장 서비스/사업자 지원 예시와 FREE의 고정 시장 지표는 외부에 제공하지 않는다.
- 화면 선택/표시 여부는 보안 권한 검사 대신 사용할 수 없다. 정식 유료 자료 연결은 서버 권한 검사/동의/결제 계약이 별도로 필요하다.

## 검증과 잔여

- 단위 시험: 기존5단계 입력, 외부 자료 유무, 샘플 분석 분리, 잔액/권한 변경 코드 없음.
- 실제 브라우저: Mantawi 샘플에서 BASIC 팝업/취소/확인/건물 제원 펼침과 GLI Cash5000 유지. CAM Realty 외부80㎡/2BR/$450 상세에서 BASIC 추가 자료 없음/비활성 확인. 새로운 유료 검색 없이 기존 저장 표본 사용.
- 영어에서 새로 공개된 샘플 상세 일부 문구가 한국어로 남아 있다. 전체 언어/휴대폰 검수는 순서7~8에 남긴다. 자료 있는 외부 publicResources 확정 화면은 후속 표본 검수가 필요하다.
- 증거: work/access-preview-20261013.png, work/access-external-20261013.png. 커밋/푸시/공개 배포/새 수집/유료 AI 없음.

## 차후 Claude 역인계

HIST-20261013-013: 같은 팝업 레이아웃으로4수단 결제 선택 목업을 재사용한다. 선택 완료는 실제 결제/계정 활성화가 아니다. 이 소규모 변경도 차후 디자인 원본에 역인계한다.

대규모 UI 개편 때 확인 팝업의 `정보 열람/정보 보기` 표현, 외부 자료 없음/비활성 표시, 화면 한정 단계 선택(실제 권한과 구분)을 승인 원본에 통합하도록 전달한다. 기존 형태/색/서체는 재설계하지 않았다.
