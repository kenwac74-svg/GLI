## 구조와 데이터 계약

- gli-locale 쿠키에 ko/en만 저장한다. 미지원 값/미설정은 기존 한국어로 동작한다. 계정/로그인이 필요 없는 표시 설정이며 권한 결정에 쓰지 않는다.
- 루트 LocaleProvider와 기존 지구본 버튼을 연결한다. Claude 원본 HTML/CSS/자료는 유지하고 등록된 텍스트·접근성 라벨만 영어로 투영한다. 입력값/사용자 발화/링크/자산 ID/가격 숫자/출처를 변형하지 않는다. 미등록 문구를 추측하거나 외부 번역 API를 자동 호출하지 않는다.
- 고정 영어 문구는 lib/english-ui-copy.ts에서 관리한다. 숫자가 포함된 제한된 UI 상태는 lib/ui-language.ts의 형식별 규칙을 사용한다. 원문 뉴스/백서/PDF/영상 등 독립 자료 전체의 번역은 별도 범위이며 UI 영어화만으로 완료를 주장하지 않는다.
- /api/search의 기존 locale 계약을 상담 공급사/규칙 fallback에 전달한다. 후보/하드 필터/근거/Trust 정책은 공통이고 답변 언어만 다르다. provider 실패 시 영어 fallback을 사용한다. 모델을 추가하지 않는다.
- 원문 통화와 매매/월 임대 단위를 유지한다. 영어 참고환산은 USD, 한국어는 KRW이며 기존 API 환율과 기준 시각을 사용한다. 언어 전환 자체로 유료 AI 검색을 실행하지 않는다.
- 이전 실제 상담 문장은 저장 당시 언어를 보존한다. 언어 변경 후 새 질문부터 선택 언어로 답하며 이전 대화를 비용을 들여 다시 번역하지 않는다. 명시적 상단 새 상담/하단 이어가기 정책을 유지한다.
- 외부 원문의 고유명사·등록되지 않은 원문 설명은 원문을 보존한다. 화면 언어와 원문 언어가 같다는 보장은 하지 않는다. 언어 전환은 원문 주장이나 수집 표본을 검증 데이터로 바꾸지 않는다.
