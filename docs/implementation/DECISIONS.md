# 사용자 결정과 개발 이력

근거는 이 작업에 제공된 사용자 대화와 저장소 문서/커밋이다. 대화에 날짜가 없는 항목은 날짜를 추정하지 않는다. `승인`은 제품 방향 또는 명시된 범위의 승인이고, 구현 완료나 출시 승인을 뜻하지 않는다.

## 현재 적용할 결정

2026-10-01 P51: 수동 입력 대시보드는 관리자 전용으로 확정. 기존 ADMIN 인증과 스타일을 재사용하고 입력은 검수 대기 초안으로 저장한다. 일반 회원 제출/데모 쓰기 허용/자동 게시/기존 공개 매물 덮어쓰기는 포함하지 않는다. [구현 범위](ADMIN.md).

2026-10-01 P50: GPT Sites에서 반영구적 DB 사용 환경을 만들라는 사용자 지시에 따라 기존 D1에 외부 발견 후보 영속 저장/상세 복원 경로를 연결한다. 저장을 검증 완료나 실시간 거래 가능 확인으로 해석하지 않는다. 관리자 DB 반입/수동 입력 가능성을 검토하며 기존 실제 ADMIN 제한을 유지한다. 공개 배포 및 새 관리자 UI는 별도 확인한다. [저장 계약과 미완료](DURABLE-DISCOVERY.md).

2026-10-01 P49: 사용자 `db1`은 Cloudflare D1으로 해석한다. 현재 GPT Sites에서는 D1 영속 저장을 우선하고 최종 AWS 이전을 목표로 백엔드를 설계한다. 업무 로직/API 계약과 DB·객체 저장소·작업 실행 adapter를 분리하며 기존 repository/RawObjectStore 경계를 재사용한다. PostgreSQL/S3는 AWS 후보이고 이전 구현·인프라 생성·배포 승인이 아니다. 중간 테스트 환경의 구체 구성은 별도 확정한다. [AWS 이식 원칙](AWS-MIGRATION.md)을 따른다.

2026-10-01 P48: 첫 질문에 국가/지역이 없으면 현재 연결된 캄보디아·베트남·필리핀을 검색한다. 후속 질문은 이전 범위를 유지하고 명시적 국가·도시 변경을 우선한다. 알려진 구역명은 해당 국가를 뜻한다. 국가별 병렬 조회/실패 분리, 동일 관측 환율 예산 비교, 통합 최대 Top5이며 국가별 강제 할당은 하지 않는다. [다국가 검색 계약](MULTI-COUNTRY-SEARCH.md)을 따른다. 시각 재설계·커밋·푸시·공개 배포 승인이 아니다.

2026-09-23 P39: 사용자 "시안을 모두 반영해서 커밋 푸시 하기 직전 버전을 보고 싶다".

## 향후 모바일 앱 출시 전제 (P29)

- 2026-09-17 사용자 확정: GLI는 향후 iOS 및 Android(AOS) 스토어 출시를 계획하며, 목업 단계부터 이를 고려해 설계한다.
- 후속 개발은 웹 UI와 도메인 로직/API의 경계를 유지하고, AI·크롤링·비밀키는 서버에서 처리한다. 앱 클라이언트에서도 재사용 가능한 데이터 및 권한 계약을 고려한다.
- 인증 세션, 딥링크, 관심 자산·상담 상태, 알림, 파일 열기와 업로드는 모바일 앱 확장 시 확인할 항목이다. 모바일 가독성, 터치 조작, 키보드·안전 영역도 검수 범위로 고려한다.
- 멤버십·GLI Cash·상품 구매는 결제 제공자와 권한 부여를 분리하고, 앱 출시 시점의 스토어 결제 정책에 따라 상품별 처리 방식을 검토한다. 현재 웹 결제를 앱에 그대로 적용한다고 확정하지 않는다.
- React Native, 웹 래퍼, PWA 등 구현 방식, 출시 일정, 앱 결제 방식은 미확정이다. 이 결정은 즉시 앱 전환이나 UI 재설계를 승인한 것이 아니다. 디자인 변경은 기존 Claude 시안·사용자 승인 원칙을 유지한다.

## 실제 AI 체험과 모델 비교 (P30/P31)

- P30 / 2026-09-18: 사용자는 제한된 비로그인/무료 실제 AI 상담을 운영자 API 비용으로 제공하는 방향에 동의했다. 공개 체험 횟수, 로그인 전후 할당량, 일일 비용 상한과 악용 방지는 미확정/미구현이다. 기존 멤버십 가격과 자료 열람권을 바꾸는 결정은 아니다.
- P31 / 2026-09-18: OpenRouter로 여러 모델의 GLI 상담 품질을 비교한다. 사용량·응답속도 최적화보다 답변 품질 평가가 우선이다. 후속 지시로 비교 대상은 Fable과 Astra로 좁혔으며 Gemini는 기존 별도 API 연결을 유지한다.
- P32 / 2026-09-18: 비교 결과 후 사용자 "진행해"로 Astra를 주 상담 모델로 사용하고 의도 해석을 실제 조회 앞에 연결하는 1차 백엔드 구현 승인. 기존 디자인/Gemini 직접 탐색을 유지한다. 로컬 검증 후 공개 배포는 별도 승인. 모든 상태/자율 도구 반복/공개 무료 사용량 정책 전체의 승인으로 확대하지 않는다.
- P33 / 2026-09-18: BuildBlock 실제 상담 벤치마크 후 사용자 "핸드오프 만들고, 네가 해야할 AI 상담 강화 계속해". Codex는 이전 후보/조건 유지, 근거 상담을 강화하고 Claude는 입력 연속성·후보 연결·조건 확인·모바일 동선의 시안을 만든다. 경쟁사 디자인 복제, 시각안 통합, 새 공개 문구, 공개 배포 승인은 포함하지 않는다.
- GLI 전용 키는 사용자 설정 총 100달러, 180일, 한도 자동 갱신 없음이다. 사용 한도는 충전 금액이나 실제 사용 승인을 대신하지 않는다. 키 값은 코드/문서/보고서/공개 클라이언트에 넣지 않는다.
- 비교 도구는 동일 질문/이력/자산 자료를 보내고 내부에 요청 모델/실제 모델/제공자/실패/사용량을 기록한다. 외부에는 기존 GLI AI 경험을 유지하며 자동 모델 대체는 하지 않는다. 비교 결과만으로 공개 기본 모델을 변경하거나 배포하지 않는다.

## P34 / 2026-09-18 외부 매물 번역 승인

- 사용자는 Gemini로 외부 매물 제목·설명·핵심 정보를 번역하고 원문과 별도 저장, 동일 원문 재사용, 목록/상세/상담 일관 적용 제안에 "적용해"라고 승인했다.
- 현재 한국어 화면에는 한국어 표시값을 사용한다. 프로젝트 고유명사, 원 가격/통화/면적/ID/출처/등급은 유지하며 직원 검증으로 간주하지 않는다. 미제공 정보를 번역 과정에서 생성하지 않는다.
- Codex 데이터 처리 범위이며 Claude 디자인·DOM·CSS·문구 체계 변경이나 공개 배포 승인은 아니다. 사용자 언어 선택 UI와 전체 다국어 사이트는 별도 범위다.

## P35 / 2026-09-23 GLI-052 보완 시안 제작 승인

- 사용자 "시작해"는 직접 Claude 조율 후 제안한 1~3번 방향의 보완 시안 제작 승인이다: 대화 내 짧은 후보 요약 최대 3건(서버 검색 상한 아님), 모바일 M2 단일 세로 흐름과 결과 바로가기, S1 조건부 따라가기.

## P46 / 2026-10-01 환율은 플랫폼 API 책임

- 사용자 지시: 원화 환율을 사용자에게 묻지 말고 환율 API로 자동 조회·계산한다. 조회 실패/지원 통화 누락도 사용자의 환율 입력으로 해결하지 않는다. 원 가격을 유지하고 환산의 일시 제공 불가만 짧게 설명한다.
- 모델 입력은 관측된 환율/환산값/기준일을 사용한다. 추정 환율·기억 기반 숫자·demo 값을 실제 환율로 승격하지 않는다. 고유명사/원 가격/디자인 규칙은 유지한다.
- 기술 현황: 공유 서비스는 최대23시간 캐시이고 공급자 snapshot 기준일을 보존한다. API 기반 자동 환산과 초단위 시장 실시간 환율을 혼동하지 않는다. 사용자 실시간 요구의 최신성/조회 주기 개선은 미완료이며 이번 작업에서 주기/공급자/설정을 변경하지 않았다.
- 기존 화면 답변은 과거 응답이다. 새 규칙/환율 전달 적용 후 실제 답변 재시험은 별도 필요하며, 기존 기록을 조용히 고쳐 성공 증거로 만들지 않는다.
