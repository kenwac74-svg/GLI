# 사용자 결정과 개발 이력

근거는 이 작업에 제공된 사용자 대화와 저장소 문서/커밋이다. 대화에 날짜가 없는 항목은 날짜를 추정하지 않는다. `승인`은 제품 방향 또는 명시된 범위의 승인이고, 구현 완료나 출시 승인을 뜻하지 않는다.

## 제안과 미확정 사항

- AWS를 대상으로 한 이식 준비는 요청 범위다. Fargate/RDS/S3/SQS 조합은 이전 답변의 기술 제안이며 공급자 계약·리전·규모·실제 이전 실행을 승인받았다는 뜻은 아니다.
- AI 월 60/150/400회는 현재 코드값이며 사용자에게 계산을 위임받아 설정한 데모 수치다. 최신 모델 단가·검색 grounding 비용을 반영한 실서비스 수익성 승인 근거는 없다.
- 추가 국가 출처, 다국어 지원 범위, Cash 만료·환불·정산, 자산별 유료 자료, 운영 SLA는 확정할 항목이다.
- 오래된 ADR에 추가된 '확인 중/해당 없음/작성일 미확인' 등의 세부 문구는 '조사 예정'이라는 사용자 확정과 구별한다. 새 문구를 UI에 넣을 때 승인 내역을 확인한다.

## 과거 문서의 충돌 처리

| 기존 기록 | 현재 해석 | 다음 개발자가 하지 말아야 할 해석 |
|---|---|---|
| 5탭/Trust Score 설명 | 8등급 공개와 승인된 접힌 상세 구조가 우선 | 내부 점수 필드를 모두 지우거나 5단계 열람권을 8개로 변경 |
| PM GLI-030 favorite limits | 현재 favoriteLimit=null | 예전 제한을 복원 |

| ADR 0021 모든 live 수집 미구현 | 이후 조건부 수집 코드는 생김, 영구 저장/재확인은 여전히 미완성 | 전부 미구현 또는 전부 완료로 일괄 판정 |
