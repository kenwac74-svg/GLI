# GLI 순차 작업 지침

사용자 확정: 2026-10-12. 기존 AGENTS.md의 안전/비용/최소 변경 원칙 안에서 이 순서를 적용한다. 사용자가 변경하지 않는 한 프론트 정리 이전에 AI 답변 품질 작업으로 넘어가지 않는다.

## 진행 방식

- 각 단계에서 문답식으로 방향을 정한다. 한 번에 질문 하나를 제시하고 답변을 기다린다.
- 완료/부분 연결/미연결, 코드 검사/실제 화면/DB/공개 환경 검증을 구분한다.
- 승인된 목업 가능 기능은 기존 화면과 API/DB를 사용한다. 영속 업무 데이터를 브라우저 저장으로 대신하지 않는다. 일시적 화면 상태와 DB 업무 데이터는 구분한다.
- 새로운 디자인/대규모 UI 변경은 Claude Design에 전달하고 승인 후 반영한다. 기존 승인 디자인의 소규모 문구·상태·동작 보완은 Codex 판단으로 수행·기록하고 차후 대규모 개편 때 Claude에 역인계한다(2026-10-13). 새 정책/실서비스 연결/실결제/권한 변경/공개 배포는 별도 승인 대상이다.
- 현재 단계가 끝나면 관련 검사와 명세/히스토리를 기록한다. 작은 수정마다 전체 빌드/배포를 반복하지 않는다.
- 날짜와 소요 시간을 추측하지 않고 단계 완료·승인으로 다음 단계에 진입한다.

## 확정 순서

1. 미연결 UI 목록 확정: 완료·부분 연결·목업 가능·정식 개발 필요를 구분하고 대상 범위를 문답으로 확정한다.
2. 관심자산 DB 연결 마무리: 외부 후보/프로젝트 안정 참조를 보완하고 실제 계정 저장·해제·재조회·상세 복귀 검수.
3. 목록 조작 기능 마무리: 정렬·그리드/리스트·필터·선택 상태·상세 복귀 일관성.
4. 상세 정보 열람 목업 연결: 기존 BASIC 등 버튼, 샘플/외부 정보 구분, 실결제/권한과 분리.
5. 멤버십·결제 시연 흐름 정리: 선택→확인→완료. 실결제·잔액·권한 정책은 별도 승인.
6. MY 목업과 전문가 문의하기 폼 정리: MY는 기본 회원 정보/로그인·로그아웃, 현재 멤버십·열람 범위, DB 관심자산 목록·상세 이동·해제로 한정한다. 전문가는 문의 폼만 포함하고 배정·예약·진행 관리 등 상담 서비스는 제외한다. 새 화면/디자인은 Claude 선행. 다른 준비 중 서비스는 제외한다.
7. 한국어·영어 및 기본 정보 표시 검수: 번역·가격·환율 시각·사진·제원·날짜, 샘플 지표 보존/외부 근거 없는 지표 배제.
8. 모바일·데스크톱 통합 검수: 잘림·메뉴·입력·로딩/오류·목록→상세→복귀.
9. 프론트 완료본 승인: 로컬 최종 시안, 변경 묶음 검증, 명세·히스토리 갱신.
10. 커밋·푸시·공개 배포: 각각 사용자 지시에 따라 수행하고 공개 화면까지 확인.
11. AI 답변 품질 개선: 응답 속도·최신 탐색·수익 근거·Top5·후속 질문 흐름을 순차적으로 개선.
