# 무료 기본 정보 보존·표시 계약

## 승인과 범위

2026-10-03 사용자 핸드오프에 따라 기본 정보의 저장 누락, 미확인값/날짜 혼동, 번역·환산 실패 은폐를 로컬에서 보완한다. GS-004/015/033. 요금제·공개 범위·디자인 재설계·추가 수집·유료 AI·공개 배포 승인이 아니다. 1002작업1 이후 로컬 변경에 누적한다.

## 구현 계약

- 수집 당시 USD 참고환산은 제공된 provider/asOf와 함께 검증·보존한다. 다음 갱신에 새 참고환산이 없으면 이전 환산을 삭제해 변경된 원문 가격에 오래된 금액을 붙이지 않는다. 화면 원화는 여전히 API 환율로 계산한다.

- DiscoveryRepository는 기본 Asset 외 공개 제원/분류/가격 설명/게시 근거/자료 라벨/공개 자료 링크/사진/원문 시각을 검증하여 보존한다. 임의 필드/비공개 메모/GLI 검증 승격은 허용하지 않는다.
- 새 목록 갱신에서 생략된 추가 필드는 기존 값을 유지한다. 제목만 반복하는 요약으로 기존 별도 설명을 덮지 않는다. 명시적으로 제공된 값/배열은 갱신되므로 세부 자료 전체의 최신성을 보장하지 않는다. 이전 자료의 원문 날짜는 새 수집일로 갱신하지 않는다.
- 원문 침실/욕실 null은 null을 유지한다. Studio는 실제 0에만 대응하고 null은 미확인이다. 미확인 침실은 침실 수 하드 필터에 부합하지 않는다.
- 원문 게시일/sourcePublishedAt, 갱신일/sourceUpdatedAt, GLI 수집/확인일/sourceObservedAt은 별개다. 외부 원문 날짜가 없으면 미확인이다. KH-LIVE 구형 updatedAt은 수집일로 생성된 경로임을 알고 있으므로 읽기 시 원문 날짜로 쓰지 않는다. 기존 DB 원문은 수정하지 않는다.
- Dot 목록 HTML에 설명/추가 사진이 이미 있으면 그 범위에서 보존한다. 최초 검색 때 모든 상세 URL을 내려받지 않는다. 원문 설명이나 사진이 없는 기존 행에 자료를 만들어 넣지 않는다.
- 관심 매물 상세 보강은 다음 단계: 출처별 허용 접근, 원문 설명/사진/제원 파서, 별도 세부 관측 시각, 기존 필드와 병합/실패 복귀 검증을 먼저 확정한다. 이번에는 새 외부 상세 수집이나 자동 보강 호출을 연결하지 않았다.
- 번역은 기존 캐시 전용 공개 조회와 고유명사 보존 규칙을 유지한다. 캐시가 없는 원문 포함 상세는 미확인을 알린다. cached는 캐시 존재이며 전수 번역 품질 인증이 아니다. 원문 가격/통화/거래 단위/출처는 번역으로 바꾸지 않는다.
- 원화는 환율 API 기반 참고가격이며 시각은 한국 시간까지 표시한다. 조회 중/실패/통화 환율 누락을 구분하고 고정 환율을 넣지 않는다. 공급사 환율의 갱신/캐시 주기는 기존 정책이며 틱 단위 실시간 가격을 뜻하지 않는다.
- 외부 상세 무료 영역의 근거 없는 고정 관심도/7일 이내/비교12건은 미확인으로 표시한다. 원문 주장을 GLI 검증 사실로 승격하지 않는다. 다른 요금 등급의 목업을 실제 분석으로 전환한 것은 아니다.

## 검수 증거와 남은 일

- 로컬 DB 읽기: KH14/VN42/PH0. 공개 DB 건수는 확인하지 않았다. PH collector의 Map과 D1은 별개이며 프로세스 Map은 재시작하면 사라진다. 공개 후보는 해당 공개 D1 바인딩을 별도로 조회해야 한다.
- SQLite 임시 DB 시험: 추가 필드 저장/조회/상세 투영, 얇은 목록 재수집 시 설명/사진 유지, 구형 KH 날짜 정정, 미확인 침실/Studio 구분. 실제 운영 DB 백필은 하지 않았다.
- 전체 검사 287개 통과, lint 오류0/기존 경고10, 타입 검사/로컬 빌드 통과. 마지막 SQL 요약 보호 보완 후 저장 관련6개/타입 검사 추가 통과.
- 로그인 없는 기존 VN 상세: GLI-VN-DOT-B375306FEC4C, 원문 35,000,000,000 VND/126㎡/3BR/2욕실. 환율 API 기준 약 1,835,180,933원, 기준시각 2026-10-02 09:02:31(KST) 표시 확인. 이것은 저장값/표시 검사이지 원문 가격의 현재 유효성 확인이 아니다.
- 로그인 없는 기존 KH 상세: GLI-KH-LIVE-56EF1E797553, 원문 USD450 월 임대/80㎡/2BR/2욕실. 원문 게시·갱신일 미확인, 수집일 별도 표시 및 무료 고정 지표 미확인 확인.
- 두 원문 URL 재접속도 실패했다. 원문 대비 위치/사진/설명/가격 정확도는 미완료다. 기존 저장 사진은 1장이고 VN42건 설명은 여전히 제목 반복이다. 추가 자료 확보에는 별도 수집 승인/접근 가능한 원문이 필요하다.
- PH 외부 수집 표본의 실제 목록→상세, KH/VN 기존 수집 목록→상세 연속 클릭, 전체 사진 로딩/번역 품질 전수 검수는 미완료다. 테스트의 PH HTML 표본은 실제 DB 저장/공개 화면 검수의 대체물이 아니다.
