# GLI 검색결과 UI — B안

기록일: 2026-10-16
브랜치: `design/gli-search-ui-b-20261016`
기준 커밋: `d00e6a7d9ff7672e0808d0f255f6b25274d26c2b` (`main`에서 분기)
상태: **기존 UI를 대체하지 않는 비교 검토용 B안. 제품 채택·병합·배포는 미승인.**

> 사용자 결정: “이 시안은 별도 브랜치에 저장하고 기존 UI를 대체하지 않는 b안으로 검토한다.”

## 원격 저장 상태 — 미완료 항목을 구별

현재 이 브랜치에는 B안의 지정·검토 범위와 자산 목록을 기록했다. **이미지 내장 HTML과 PNG 원본의 GitHub 업로드는 아직 완료하지 못했다.** 원본은 대화 첨부의 검토패키지 및 `GLI_B안_브랜치보관_20261016.zip`에 보존되어 있다. `ASSET_MANIFEST.json`은 원본 식별용 목록이지 모든 파일이 이미 원격 저장되었다는 증거가 아니다.

현재 연결 도구는 텍스트 내용을 직접 받지만 로컬 파일을 전달받는 업로드 동작이 없고, 로컬 Git은 GitHub에 접속하지 못했다. 원본을 축소하거나 내장 이미지를 빼서 다른 시안으로 저장하지 않았다. 파일 업로드 후 실제 원격 크기·해시를 확인하기 전에는 보관 완료로 바꾸지 않는다.

## 검토 범위

대상은 `GLI_검색결과_클릭형시안_v1.html`이다. 이전 Claude A안, 생성형 대시보드 이미지 또는 현재 운영 UI와 혼동하지 않는다.

- 기존 GLI의 가로 메뉴·검색·상담·필터·목록 역할을 참고하는 독립 HTML 시안이다. 제품 소스를 그대로 복제한 것은 아니다.
- 후보 찾기 → 두 후보 비교 → 관리비 질문의 세 예시에서 필요한 답변 표현이 달라지는지 검토한다. 세 장면을 전체 질문의 고정 양식으로 승인한 것은 아니다.
- 사용자가 만족한 Instant 답변을 활용하되 사진·수치·출처·가정·미확인 사항을 왜곡하지 않는지 확인한다.
- 비교·관리비는 미리 작성한 예시다. 자유 질문 AI, 실시간 검색, 관리자 검색명령 저장, 상담·조사·결제 접수는 연결하지 않았다.

## 변경 경계

이 브랜치는 비교 검토용 보관 공간이다. `main`, 운영·개발 기준 브랜치, 기존 UI, 앱 라우트·컴포넌트·DB·배포 설정·PR #3을 변경하거나 이 B안을 병합하지 않는다. 기존 UI가 기준이며 B안의 채택 여부는 별도 결정한다.

화면이 보기 좋다는 이유로 시안에 없는 기능이나 과금·검증 정책을 추가하지 않는다. 질문에 맞춰 표현을 고르는 것과 답변을 고정된 빈칸에 끼워 맞추는 것을 구별한다.

## 파일과 검증

원본 파일명·바이트를 유지한 업로드 준비 묶음은 이 폴더와 같은 상대경로로 구성되어 있다. 파일명·크기·SHA-256은 `ASSET_MANIFEST.json`을 따른다.

- `GLI_검색결과_클릭형시안_v1.html`: 이미지·코드를 내장한 원본.
- `GLI_클릭형시안_변경설명.md`: 원래 변경 설명과 범위·한계.
- PNG 4개: 첫 화면, 후보 탐색, 두 후보 비교, 관리비 질문.
- `검증/test_results.json`: 이전 제작 단계의 27개 검사 보고. 이번에 새로 제품 검증을 실행했다는 뜻이 아니다.

이번 보관 준비에서는 원 ZIP의 손상 여부와 복사된 7개 파일의 일치를 확인했다. 앱 기능을 수정하지 않았으므로 서비스 테스트·빌드·배포는 실행하지 않았다.

## 이어받는 개발 담당의 남은 일

B안 업로드 준비 ZIP의 `docs/design-alternatives/search-ui-b/` 아래 원본 7개를 **이 브랜치에만** 추가하고 원격 해시를 확인한다. 필요하면 분리된 작업 폴더를 사용한다. 원본 업로드 외 UI 수정·강제 푸시·병합·배포를 하지 않는다. 원격 저장이 확인되면 이 문서의 업로드 상태만 실제 상태로 갱신하고 커밋을 보고한다.
