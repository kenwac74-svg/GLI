# P-010 API case 1

Question: 베트남 호치민에서 1억 5천만 원으로 임대수입을 기대할 만한 아파트를 찾아줘.

**1억 5천만 원으로 호치민 임대용 아파트를 찾는다면, 현재 확인한 매물 중에서는 ‘EHomeS 남사이공·미즈키 인근 50㎡’를 먼저 검토할 만합니다.** 다만 **현재 환율과 외국인 명의 취득 가능 여부를 확인하지 못해, 예산 내 매수 가능 또는 임대수익 확보를 확정할 단계는 아닙니다.**

아래는 2026년 10월 30일 기준 웹 검색에서 확인한 **매도 광고 후보**입니다. 실거래가격이나 현재 매물 잔존 여부까지 검증한 것은 아닙니다.

## 1. 우선 검토 후보

|---|---:|---|---|

## 2. 1억 5천만 원 안에 들어오는가?

현재 원화·동화 환율을 검증하지 못했으므로 원화 환산가격을 임의로 제시하지 않겠습니다. 대신 **예산 충족에 필요한 환율 기준**은 계산할 수 있습니다.

- **25.3억 동 매물:** 1원당 약 **16.87동 이상**
- **25.5억 동 매물:** 1원당 **17동 이상**

이는 **매매대금만** 1억 5천만 원에 맞추는 기준입니다. 환전·송금 비용, 별도 세금과 수수료, 가구·수리비, 공실 대비 자금까지 포함한다면 더 여유가 필요합니다. 광고의 “세금·명의이전 비용 포함”도 계약서에서 부담 범위를 확인해야 합니다.

## 3. 임대수입 관점에서의 판단

### EHomeS: 가격 후보이지, 아직 수익형 매물로 검증되지는 않았습니다
50㎡·침실 1개라는 조건은 소형 임대상품으로 검토할 수 있지만, **이번 검색에서는 해당 단지의 실제 임대료·공실률·관리비를 확인하지 못했습니다.** 따라서 예상 월세나 수익률을 제시하는 것은 근거가 부족합니다.

특히 광고에 “상업주택”이라고 쓰여 있어도, **해당 호실이 외국인 명의로 취득 가능한지는 별도 확인 사항**입니다. 단지명이나 광고 문구만으로 판단하면 안 됩니다.

### Akari City: 광고 수치 기준 표면수익률은 약 3.8%
광고의 매매가 47억 동과 월세 1,500만 동을 그대로 적용하면:

**1,500만 동 × 12개월 ÷ 47억 동 ≈ 연 3.8%**

이는 **광고 주장에 기반한 비용 차감 전 계산값**입니다. 실제 계약서와 월세 입금내역은 미확인이며, 세금·공실·수선비·중개비 등을 반영한 순수익률은 더 낮아집니다.

## 제 추천

**지금은 EHomeS 25.3억 동 매물을 ‘조건부 1순위’로 두되, 계약금부터 보내지는 않는 것이 좋겠습니다.** 아래 세 가지를 통과해야 임대용 투자로 추천할 수 있습니다.

1. **취득 가능성:** 한국인 개인 명의로 해당 호실을 매수할 수 있다는 독립적인 법률 확인
2. **임대 근거:** 동일 면적의 최근 체결 임대차계약 사례와 실제 월세 입금내역
3. **총투자비:** 원화 환산 매입대금에 모든 부대비용을 더해 1억 5천만 원 이내인지 확인

**1억 5천만 원이 부대비용까지 포함한 총예산인지, 별도 대출 없이 한국인 개인 명의로 매수하실 계획인지**에 따라 후보 적합성이 크게 달라집니다. 현재 확보된 자료만으로는 “살 만한 저가 후보”는 제시할 수 있지만, “안정적인 임대수입이 확인된 예산 내 매물”이라고 단정할 수는 없습니다.
