# P-010 API case 5

Question: 방금 보여준 두 번째 아파트는 관리비가 월세에 포함돼?

**두 번째 매물은 관리비가 월세에 포함되는지 아직 확인되지 않았습니다.** [해당 공고](https://propertyhub.in.th/en/listings/chambers-on-nut-station-pn-00006640---4963170)를 다시 확인했지만, 월세 **16,000바트·1년 계약·보증금 2개월·선불 월세 1개월**만 명시되어 있고 관리비 포함 여부는 적혀 있지 않습니다.

따라서 제가 앞서 안내한 **16,000바트를 관리비 포함 금액으로 보시면 안 됩니다.** 중개인에게 아래처럼 서면 확인을 받는 것이 좋습니다.

> Does the THB 16,000 monthly rent include the common area maintenance fee? Are electricity, water, and internet charged separately?
> 월세 16,000바트에 공용 관리비가 포함되나요? 전기·수도·인터넷은 별도인가요?
